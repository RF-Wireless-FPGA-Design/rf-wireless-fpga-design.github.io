## Rubik Pi 3 companion course

The full Rubik Pi 3 course curriculum and lab planning is maintained in the [Qualcomm Rubik Pi 3](https://github.com/RF-Wireless-FPGA-Design/Qualcomm-RubikPi3) repository: start with the [course roadmap](https://github.com/RF-Wireless-FPGA-Design/Qualcomm-RubikPi3/blob/main/planning/course-roadmap.md), the [development plan](https://github.com/RF-Wireless-FPGA-Design/Qualcomm-RubikPi3/blob/main/planning/implementation-plan.md), and the [Wi-Fi guide](https://github.com/RF-Wireless-FPGA-Design/Qualcomm-RubikPi3/blob/main/network/wireless-connection/wifi-setup.md). The curriculum includes networking, wireless communications, AI/ML, edge deployment, 5G/O-RAN and capstones. New labs are planned, not yet board-validated.
